# Quaternius medieval village, December 2020

- Author: Quaternius
- Source page: https://opengameart.org/content/lowpoly-medieval-village-pack
- Licence on that page: CC0, linking http://creativecommons.org/publicdomain/zero/1.0/
- Download: https://opengameart.org/sites/default/files/medieval_village_pack_-_dec_2020.zip
- Retrieved: 2026-11-21

The page itself is marked CC0. The zip is Blend, FBX, and OBJ. The models kept
here were converted from the author's OBJ and MTL into glTF so the game can
load them the same way as the trees. Mesh positions are the author's. Colours
are the MTL diffuse colours (`Kd`).

Kept: House_1 through House_4, Inn, Bell_Tower, Blacksmith, Mill, Stable,
Sawmill, Fence, Hay, Well, Barrel, Bench, Cart, Bonfire_Lit, Path_Straight.
